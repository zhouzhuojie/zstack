### Shipping

Landing finished work on its branch and handing it over. Nothing here
pushes or merges without the user's word.

1. The adapter's broad gate green on the final tree. Paste the PASS tail.
   Scan the gate's logs for errors even when the summary is green.
2. Docs describe the present: behavior or numbers changed → the doc truth
   is updated in the same commit, or the commit message says why docs are
   unchanged. No iteration diaries; process goes in the commit message.
3. Reread the diff cold and cut slop: dead comments, debug prints, scope
   beyond the ticket.
4. Present: branch, commits, gate output, and the one thing most worth
   human judgment; landing waits for the user's word per SKILL.md's
   non-negotiables.
5. Release tier only when asked: the adapter's `release gate`.

**Reply:** branch + commits + gate evidence, one line on known limits.
